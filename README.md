# 庶政学 · 数理政治哲学标准模型

一个**静态**的阅读网页 ＋ 专家策略台：一边把政治立场读成基本初等函数，一边把 13 讲的**全文整理稿**按概念检索。
双击 `index.html` 即可打开，不需要服务器，不需要联网（时间锚点跳 B 站时才需要）。

## 两层展开与实时坐标系

三处把文章接回坐标系的补充，都是**加法**，不改已有架构：E02 展开第三轴，E08 展开 X 轴的负向，
文献视图再用一个实时坐标系把段落接回平面。

### 一、模型视图的第三轴层（E02）

E13 说，加入第三轴（虚数轴＝暴力）之后「它就是权力的模型」，作者同时声明「他就不是庶政学了，他就是权力学」——
但他也承认这一层那一讲没做，只是前向预告。补上它的是 E02《权力的三个基本性质》。打开左侧的**虚数轴**，这一层就展开：

| E02 的性质 | 读哪条轴 | 画布上怎么看 |
|---|---|---|
| 质 | 纵轴 · 对价侧 | 横轴本身就是**对价线 y = 0**：线上不计代价，只有第一人称报告，没有质。向下一档一条虚线，刻度直接用已有的**单元阈值**：0～−1 单元＝一般的违禁·法度，−1～−2＝苟合·伦理，再深＝人命·生死 |
| 秘密性 | 横轴 · 纲领↔习俗 | 轴上方左右各一句：习俗侧，秘密以默契与丑闻存在；纲领侧，秘密以制度与档案存在 |
| 概率性 | 第三轴本身 | 不落在平面上任何一点，它是对整个平面的限定——曲线只给趋势，趋势不是担保 |

**边界**：E02 通篇不说纲领、习俗、对价——它的整理稿里这几个词除标题外零出现。所以「三条性质挂到三条轴上」是整理者的〔补〕，
页面里逐条标出；分档与当量也是补足。每条判语都挂 E02 关键词，点按跳到文献视图的对应段落。
讲义里标〔疑〕的三处（三级阶梯与三种变形的对应、落点归位、「指证」用字）在读数里同样标〔疑〕，不写成定论。

### 二、X 轴左侧的九连环（E08）

E08《X 轴左侧的情形：九连环》本来就是讲坐标平面的一个区域，所以这一层几乎不用翻译——
打开左侧的**九连环**，横向视野会从 ±5 放到 ±9，负向轴上钉出九个环节：

| 环 | 位置 x | 环节 | 文稿的说法 |
|---|---|---|---|
| 1 | 0 | 主体性 | 原点：心灵、机心巧智。「第一环是松的」 |
| 2 | −1 | 身体 | 身体、行动；与第一环可以一块放下 |
| 3 | −2 | 家庭 | 伦理依托，不能直接放下 |
| 4 | −3 | 家族 | — |
| 5 | −4 | 同乡 | 同语言、同方言 |
| 6 | −5 | 文明圈 | 同习俗的范围 |
| 7 | −6 | 生殖宗教 | 人格化神灵、泛灵崇拜 |
| 8 | −7 | 宇宙宗教 | 自然秩序 |
| 9 | −8 | 本体论宗教 | 存在论秩序 |

这一讲的总纲是一句反直觉的话：**「政治的灵魂是交易」**——体系的精髓在 **Y 轴的下半部分**，
上半轴是义务性的、奉献性的；「那其实是政治操作的真正的宝库、宝藏」。所以画布上把 y &lt; 0 那一半标成**交易位面**。

几何要竖着看，不要平着看。九连环的每一环只有两个位置：**挂在架上**，或者**垂脱在下面**。
文稿原话：「第七环挂在上面，下面六环都是垂脱的、掉下去的」；「前面其他的六个环全都耷拉在下面」；
「你想把第五个环、第六个环再放上去，不行，放不了，他已经进入交易的位面了」。
而「放下来就是进入交易的层面」——所以**上＝神圣位面（y > 0），下＝交易位面（y < 0）**。
九个环的姿态合起来是一张**配置**，不是一条队列：X 轴只回答「哪一环」，Y 轴回答「挂着还是垂着」。

规则照九连环本身（也照文稿）：**第 1 环永远可动**（「你的心灵永远是自由的」）；第 1、2 环可以一块放下；
第 n 环可动当且仅当**第 n−1 环在架上**、且**第 1..n−2 环都已解下**——
「它前面所有的环都被解开，除了它前面的、直接的前面那个环没被解开」。
于是要把第 3 环挂上去，次序只能是 1 上 → 2 上 → 1 下 → 3 上，正是文稿写的那串动作。

**怎么操作**：点画布上的环就能试着把它挂上去或放下来（点的位置在轴上方＝挂上、下方＝放下），
动不了的环会被拦下并说明原因；虚线圆圈标出此刻可动的环。九环全挂上时只有第 1、2 环可动；
照文稿的例子把 1–6 环垂下、第 7 环挂在架上，可动的就只剩第 1 环与第 8 环——
这就是**越权禁止**：低阶的环节不能靠一道法令重新变神圣，只能一环一环挂回去。

三条硬约束照原文：**相邻性**（只能解高一层的）、**单向性**（垂下去就「已经去魅了」，想挂回去得重走全套）、
**越权禁止**（神圣性不能靠一道法令造出）。

**边界**：九个环节的名字与次序照文稿原话落位；环的上下两态与「哪一环能动」的规则也都是原文。
本页的〔补〕只有一处——把「上／下」对应到 Y 轴正负，文稿虽说了「放下来就是进入交易的层面」，
但没有把它写成坐标刻度。另：文稿还有一版更细的层次序列（多出神学时空论、世俗统治神学，
并把「同乡」写作「语言排他性」），作者自己说「这个有没有九个？如果不够九个我再加一个」，本页取他明确数过的那九个。

### 三、文献视图的实时坐标系

读文章时，指针移到哪一段，右侧的坐标就滑到那一段在讲的位置：函数族、参数、探针位置、以及第三轴那一层的开合。
机制是 [axis-map.js](axis-map.js) 里的三层匹配，顺序不能反：

1. **正文精确规则**（1/x、圆的诞生、虚数轴、视差、四重性…）
2. **小节标题**（幂函数 / 指数函数 / 对数函数 / 三角函数 / 常数函数…）
3. **正文兜底**（庶政学的由来、数学作为沙盘…）

先跑正文再跑标题会互相遮蔽——例如「对数函数」那一节的正文里提到了「幂函数」，若让正文先跑，整节都会被判成幂函数。
没有对应状态的段落（如勘误表）不跳转，只换提示、画面留在原处，免得读表格时图一直闪。

```powershell
node tools/check-axis.mjs          # 映射命中率 + 待命规则
node tools/check-axis.mjs E02      # 逐块打印：哪一块命中了哪条规则
```

## 整理口径：全文整理，不是总结

本仓库的文字稿按用户的《文字稿优化》规范执行，**铁律**如下：

| 允许 | 禁止 |
|---|---|
| 修正语音转写错误（要有依据） | **压缩篇幅、删减观点或细节** |
| 去除口头重复、语气词、演示指示语 | 重排讲述顺序 |
| 按讲述逻辑划分小节、加标题 | 增补原文没有的内容 |
| 指代不清处按上下文理顺 | 用“总结/摘要”段落替代原文内容 |

- 本次采用**口径 B · 通顺化**：口语转通顺书面语，删语气助词与现场插话，**删时间戳**，枚举条目列表化；**篇幅必须落在原文的 80%–110%**，信息点一一对应。
- 逐讲附《语音转写勘误对照表》（原文转写 → 整理后 → 依据），无法确定的写法标〔疑〕，不臆造。
- 早先按“讲义”口径产出的 13 份摘要稿（把 3 万字讲成 1 万字）不符合铁律，已移入 `文稿-讲义/` 存档，不进网页。

## 重新生成

```powershell
# 1) 新稿件入库
node tools/srt2txt.mjs                                            # B 站字幕
powershell -File tools/docx2txt.ps1 -Path <某个.docx> -Out .docx-raw.txt # 会议逐字稿
# 2) 切块 → 派分块整理 → 分块稿落在 文稿/parts/

# 3) 一趟跑完：汇编 → 语气助词清理 → 覆盖率 → 编译 → 规则出处校验
powershell -File tools/verify-all.ps1
```

单步等价于：


### 三处「疑似给错」的核对结论

| 审核意见 | 核对结果 |
|---|---|
| 反三角特征点应为 $(1,0)$ | 原文确实说「反三角函数会 $(1,0)$」，但整理稿自己就标了〔疑〕，而 $\arctan 0=\arcsin 0=0$。**保住 $(0,0)$，改用〔疑〕说明** |
| 「前现代保守」挂错到指数函数 | **不成立**。原文：「所以这个是一种现代的一种保守、现代保守；刚刚那个讲的是一种前现代保守。」「这个」指对数，「刚刚那个」是紧挨着讲完的指数函数 |
| 常数函数「取导数同一」未标〔疑〕 | **成立**，已补：作者自称「当然这都是假设」，讲义另标〔疑：所指不明〕 |

### 顺带修掉的一个隐藏缺陷

`model.js` 用 `ResizeObserver` 观察 canvas，而 `layout()` 每次都重设 `canvas.width` —— 赋值本身会清空画布，
画布的固有尺寸又反过来影响布局。右栏内容一长（例如展开权力学层），观察器就自激，表现为**画布一直空白**。
现在 `layout()` 在尺寸没变时直接返回，不再重设尺寸。

## 版式约定

模型视图是一台仪器，不是一篇文章。这几条是踩过坑之后定下来的：

- **画布只放机关**——环、探针、两条轨、对价线。名字一律不上画布：九环的名字在画布下方的图注里，
  其余名字在右栏。早先把环名直接排在曲线上，结果和刻度、旧标注、探针读数互相压叠。
- **一层一色，层与层互斥**——虚数轴（第三轴）与九连环是两套读法，同时开只会互相打架，所以做成互斥开关。
- **标注按模式收起**——九连环模式下不画关键点、不画定义域边界，负向刻度让位给环号，
  否则一屏里会同时出现「环号 1–9」与「x 轴 −8…8」两套数字。
- **右栏是读数，不是论文**——长篇论述（互质、失真、制度与代价、九连环的四条规矩）默认折叠，内容还在，点开才见。
  左栏开关按「同一张图上的运算」与「换一层看」分组，不再平铺成一列。
- **首屏要见到仪器**——报头压到四分之一屏以内。
- **拖动探针不重建整块右栏**——重建会丢掉右栏的滚动位置，读长文时一拖就弹回顶部；
  现在按帧合并，并在重建前后接住 `scrollTop`。

## 忠实性边界

- `原文/` 只做机械处理（合并成段、加时间锚点、docx 转纯文本），不改字。
- `文稿/` 由 AI 逐讲整理：删口吃与重复、补标点、纠正有依据的同音错字；改动逐条进勘误表，无法确定的写法保留原字并标〔疑〕。
- 策略台的规则链：出自文稿的标出处（点按可跳到该讲对应段落），属形式化推理的标〔补〕，包括策略适配度的打分公式。
- 页面不替作者指定他没有指定的东西（例如纳粹主义、工团主义、民族主义各对应哪条曲线）。
