# 庶政学文字稿整理规范（口径 B · 全文整理，不总结）

> 本规范取代此前的「讲义」口径。此前的讲义稿（把 3 万字讲成 1 万字）属违规的**总结**，已移入 `文稿-讲义/` 存档，不再进网页。

## 0. 铁律

| 允许 | 禁止 |
|---|---|
| 修正语音转写错误（要有依据） | **压缩篇幅、删减观点或细节** |
| 去除口头重复、无意义语气词、转写乱码 | 重排讲述顺序 |
| 按讲述逻辑划分小节、加标题 | 增补原文没有的内容 |
| 指代不清处按上下文理顺 | 编造无法核实的事实 |
| 枚举条目列表化 | 用“总结/摘要”段落替代原文内容 |

**篇幅：整理后 ÷ 原文 = 80%–110%。信息点必须一一对应，一条都不能丢。** 原文里的数字、人名、地名、机构名、日期、案例细节、比喻、脏话与尖锐用词，全部保留。

## 1. 本次口径：B · 通顺化

1. 口语转通顺书面语；但**不改变作者观点、判断与语气强度**。
2. 删：语气助词（啊／嗯／呃／哦／噢／嘛／呀／吧／呢／哈／嘿／唉／啧）、口头语（“对不对”“你懂吧”“你知道吧”）、结巴与机械重复、演示指示语（“我们看这里”“能听见吗”“声音小一点”）、与内容无关的现场插话。
3. 保留：专名内用字（如“哈马斯”的“哈”）；口语风格词本身表意时（如“随便怼一个模型”“贴身肉搏”）保留。
4. 真重复（同一内容讲了两遍）→ 合并为信息更全的一版，**不丢增量信息**。
5. 剔除后清理粘连标点（段首逗号、“：，”“，，”“，——”）；原靠“，对不对？”收尾的陈述句，问号改句号。
6. **时间戳不进整理稿**（原文里的 `[[mm:ss]]` 一律删除）。
7. 作者口播列举三项以上时，用 Markdown 列表（`-`）排成条目；作者用“第一／第二／第三”叙述时，保留序号文字。
8. 文中提到的公式用 LaTeX 行内 `$...$`（$y=x^{a}$、$y=\log_{a}x$、$y=a^{x}$、$y=\cos x$、$(1,1)$、$(0,1)$、$(1,0)$、$i^{2}=-1$、$e$、$\pi$ 等）。

## 2. 分块作业（本批采用）

长稿按 `原文/parts/` 里切好的分块文件作业，每块一个整理者，互不重叠：

- 输入：`原文/parts/E##-pN.txt`（自带文件头，正文为该块的范围；块边界只在段落处切）
- 输出：`文稿/parts/E##-pN.md`
- **不要写 front matter**（页头由汇编脚本统一生成）。
- 一级小节用 `### 小节名`（**不要自己编号**，编号由汇编脚本统一加“一、二、三…”）。小节数量按内容定：一段完整论述一个小节，通常每 1500–3000 字一个小节。
- 块与块之间不要写过渡句、不要写“本段完”“下接第 N 部分”之类的话，也不要重复上一块末尾的内容。
- 块末尾另起一节：

```
## 勘误（本块）

| 原文转写 | 整理后 | 依据 |
|---|---|---|
| …… | …… | …… |
```

勘误表只列**真正改了字**的地方（同音错字、人名地名机构名、专名、数字、术语），普通的口语删减不算勘误。依据写：上下文语境的判断、本讲其它处的自证、E## 讲里的同词、常识/史料。无法确定的写法在“整理后”列后加 `〔疑〕`。

## 4. 自检清单（交稿前逐条过）

1. 我这块的字数 ÷ 原文块字数是否落在 **0.8–1.1**？
2. 原文里的定义、判据、例子、数字、人名地名机构名、比喻是否**一条不漏**？
3. 有没有把观点写成概述句？（“作者认为……很重要”这类句子一律不允许，要写他具体说了什么。）
4. 有没有残留语气助词、结巴、口头语、时间戳？
5. 小节标题是否是**内容性的**（能看出这一段在讲什么），而不是“第一部分”“继续”这类空标题？
6. 勘误表是否只列真正改字处，并给出依据？
